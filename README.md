## Description
This project is a web-based application designed to help users track and monitor their daily water intake. The system allows users to log water consumption and view their progress over time.

This project was developed as part of a team, with a focus on building a functional and user-friendly interface while collaborating using version control tools.

## Features
- Log daily water intake
- Track progress over time
- Simple and user-friendly interface
- Organized data display for easy monitoring
